# Atlas Docs 3.3.0

The private calendar brings personal appointments, recurring Todos and Space
task deadlines together. It is available to every active user at `/calendar`,
including accounts without Space membership.

- Month, week, day and agenda views with Atlas controls, light/dark themes and
  English/German text; a new mobile calendar starts in agenda.
- Saved source selection, newly visible Spaces, All/Mine task filters, optional
  completed tasks, undated tasks and an overdue overview.
- Private appointments with location, description, all-day dates and stored
  IANA time zones; personal Todos with optional deadlines and priority.
- Daily, weekly, monthly and yearly recurrence, interval and count/end date,
  single-occurrence exceptions and following-series edits/deletes. Past
  occurrences remain; Todo completions apply to each occurrence separately.
- Multiple Space-task assignees, default creator assignment for new tasks,
  eligible active Space members and targeted links back to the task's board.
- Space task edits use the original Yjs board and wait for SQL persistence.
  Current access, task dependencies and concurrent changes are checked;
  unconfirmed/conflicting drafts remain visible.
- Shared Todo code for web, collaboration and migration, an atomic SQL
  projection and a locked, idempotent legacy backfill that preserves damaged data.
- Gantt archives retain source, downloads and version history. Gantt creation
  and planner settings are hidden.
- Personal calendar JSON export and owner-scoped calendars in portable ZIP
  exports. Full PostgreSQL backups include every new table.

Upgrade all three images to `3.3.0` together. Back up before stopping writers
and applying the additive migration; review migration logs for damaged boards.
No additional environment variable or Compose service is required. See
[SETUP.md](https://github.com/Timo348/Atlas-Docs/blob/v3.3.0/SETUP.md#upgrade-to-330)
and [UsageGuide.md](https://github.com/Timo348/Atlas-Docs/blob/v3.3.0/UsageGuide.md).
