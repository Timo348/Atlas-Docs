# Atlas Docs 3.1.0

Atlas Docs 3.1.0 makes Todo creation focused and complete: **Add task** now
opens a dialog for title, Markdown description, status, priority, and deadline.
Todo cards render their description and expose the same dialog through the edit
control.

## Upgrade notes from 3.0.0

1. Create the standard `upgrade` backup and use the files from tag `v3.1.0`.
   Preserve the existing secret `.env`; do not overwrite it with `.env.example`.
2. Set the exact matching image version:

   ```dotenv
   ATLAS_VERSION=3.1.0
   ```

3. No new environment variable, Compose service, or Prisma migration is
   required. Existing Todo tasks remain valid with an empty description.
4. Validate and start the matching services:

   ```bash
   docker compose config --quiet
   docker compose pull
   docker compose up -d --no-build
   docker compose ps -a
   docker compose logs --no-color migrate
   ```

Linux/amd64 `web`, `collab`, and `migrate` images are published in GHCR and
Docker Hub with `3.1.0`, `3.1`, `3`, and `latest` tags. Keep all Atlas services
on one matching tag.
