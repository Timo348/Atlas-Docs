# Atlas Docs 3.2.0

AtlasDoc keeps the caret in place while typing, so `hallo` is stored as `hallo`.
Markdown tables accept complete sentences, including spaces between words.
Markdown, text, LaTeX and AtlasDoc now expose Undo/Redo buttons and support
Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z and Ctrl+Y. Local history preserves collaborators'
changes and restores the editing position.

Admins can grant or revoke Metrics access in User management. Granted members
see the instance dashboard in navigation and Settings and can access aggregate
Prometheus data through their session. Automated scrapes retain their separate
bearer token. Document and attachment uploads are included in storage metrics.

The duplicated space picker above the document is removed. The navigation
picker and Ctrl/Cmd+Shift+K remain available. The editor review also fixes
AtlasDoc provider reconnections on language changes, viewer initialization and
drag cancellation. Next.js and sharp receive security patch updates.

## Upgrade notes

- Set `ATLAS_VERSION=3.2.0` for web, collab and migrate. Matching Linux/amd64
  images are published in Docker Hub and GHCR under `3.2.0`, `3.2`, `3` and
  `latest`. Use `ATLAS_IMAGE_REGISTRY=docker.io/timo348` for Docker Hub.
- Replace or merge `compose.yml`, `compose.build.yml` and `compose.airgap.yml`
  from the release. Only version defaults change; there are no new, renamed
  or removed environment variables or Compose services. Keep your secret
  `.env` and merge the examples deliberately.
- The additive migration adds `User.metricsAccess` (boolean, default `false`).
  Existing members receive no metrics grant automatically. Admins retain
  access. Rollback can retain the unused column with the older application;
  dropping it loses grants and requires stopping all newer services first.
- `PROMETHEUS_METRICS_TOKEN` remains optional, with no default value. Empty
  disables bearer scraping while authorized Atlas sessions still work.

```bash
docker compose config --quiet
docker compose pull
docker compose up -d --no-build
docker compose ps -a
docker compose logs --no-color migrate
```

See [the setup guide](https://github.com/Timo348/Atlas-Docs/blob/v3.2.0/SETUP.md#upgrade-to-320)
for the upgrade procedure and [the review](https://github.com/Timo348/Atlas-Docs/blob/v3.2.0/docs/EDITOR_REVIEW.md)
for resolved findings and existing limitations.
