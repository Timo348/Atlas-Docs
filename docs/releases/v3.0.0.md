# Atlas Docs 3.0.0

Atlas Docs 3.0.0 delivers a central Settings page, file-specific opening
preferences, full-screen viewers, visual Gantt planning, broader file support,
and operational observability.

## Highlights

- Account, design, workspace, per-file view, Gantt appearance, and export
  controls are now collected under `/settings`.
- Mermaid, Gantt, Todo, and plain-text files join Markdown, LaTeX, Canvas,
  PDFs, and uploaded files. Browser-native previews keep viewable uploads
  available without modifying their bytes.
- Gantt now has a direct planner: task dialog, start/end dates, drag and resize,
  double-click editing, Mermaid import, today navigation, past-date dimming,
  and user-configurable status meanings/colors.
- All file viewers have a full-screen mode with the exit control in the same
  place as the open control.
- Administrators get an instance dashboard, while Prometheus can read aggregate
  operational metrics from a separately bearer-protected `/api/metrics` route.

## Upgrade notes

1. Follow the [safe upgrade procedure](https://github.com/Timo348/Atlas-Docs/blob/v3.0.0/SETUP.md#standard-safe-upgrade): create an `upgrade` backup, then stop `web` and `collab`.
2. Replace Compose files from the `v3.0.0` tag, preserve the existing secret `.env`, and merge:

   ```dotenv
   ATLAS_IMAGE_REGISTRY=ghcr.io/timo348
   ATLAS_VERSION=3.0.0
   # Optional; leave empty to disable /api/metrics.
   PROMETHEUS_METRICS_TOKEN=
   ```

3. Run:

   ```bash
   docker compose config --quiet
   docker compose pull
   docker compose up -d --no-build
   docker compose ps -a
   docker compose logs --no-color migrate
   ```

The migrations add new file and preference data and normalize older PDF
metadata. Restoring the pre-upgrade database backup is the rollback path.

Linux/amd64 `web`, `collab`, and `migrate` images are published to GHCR with
`3.0.0`, `3.0`, `3`, and `latest` tags. Keep all three services on one matching
tag.
